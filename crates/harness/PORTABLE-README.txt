CoD4 engine test harness

1. Unzip this folder anywhere.
2. Double-click cod4e-harness.exe. A console window opens.
3. If it cannot find your Call of Duty 4 install it asks for the folder
   (the one containing "main" and "zone").
4. Wait for it to finish (about 10 minutes once all stages exist; the first
   stages are quick). The client stage needs a GPU and a display; it records
   one short video (a few MB) per display mode, and is skipped when the
   client or a display is missing. It writes cod4e-run-<date>.zip next to the program.
5. Send that zip. It is scrubbed of your user name, home folder and host name,
   and holds no game files. It stays under 100 MB.

Nothing is installed; delete the folder when done.
